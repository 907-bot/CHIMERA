# Contributing to CHIMERA

## Workflow Guidelines

1. **Branch Naming**: Use feature-based branches: `feature/phase1-integrators`, `fix/collision-math`, `benchmark/hidden-laws`.
2. **Commit Messages**: Write descriptive commit messages referencing phase numbers and components.
3. **Pull Request Validation**: All PRs must pass `pytest` unit and scientific tests.
4. **Multi-Agent Coordination**: Follow division of labor rules defined in [AGENTS.md](file:///Users/abhishekadari/projects/CHIMERA/AGENTS.md).
